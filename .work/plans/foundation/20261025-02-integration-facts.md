| # | External system | Direction | Protocol | Owner of the contract |

There is **no** outbound business integration: the toolchain never calls a third-party API at runtime.

## 2. E1/E2 — Secrets Manager wire contract

| Fact | Value | Evidence |
|---|---|---|
| Protocol | AWS JSON 1.1, `X-Amz-Target: secretsmanager.<Op>`, `Content-Type: application/x-amz-json-1.1` | `openapi.yaml`; contract rules R1–R10 |
| Operations | **17** (data plane 13 + credentials 4) | `operations.mjs:75-139` |
| Paths | `POST /`; `GET /healthz`, `/readyz`, `/` (\| `/info`) | `server.mjs:389-431` |
| Auth | SigV4, region-scoped, 900 s clock skew, timing-safe compare | `sigv4.mjs:269,327` |
| Error envelope | `{"__type":"<Code>","message":"<text>"}` | `errors.mjs` |
| Body limit | 1 MiB → HTTP 413 | `server.mjs` `readBody` |
| Admin plane | loopback `127.0.0.1:8081`, credentials operations only | ADR 003; contract BC9 |

**Deliberate AWS deviations** (must be documented for SDK users):

1. `*ClientCredential` operations are **not** AWS operations; a stock SDK will not know them. They are only reachable on the loopback listener.
2. A secret in its recovery window returns `InvalidRequestException`, matching AWS — documented because callers often expect `ResourceNotFoundException`.
3. `GetRandomPassword` is generated by the service, not by the shared Python generator.

## 3. E3/E4 — Edge facts

| Fact | Value |
|---|---|
| Public surface | TCP 80 (redirect) and 443 only |
| Host preservation | `proxy_set_header Host $http_host` — **required**, SigV4 signs `Host` |
| Client identity | nginx sets `X-Real-IP` from `$remote_addr`; `X-Forwarded-For` is **appended** (`$proxy_add_x_forwarded_for`), so its first hop is caller-controlled (`APP-01`) |
| Credential-op deny | `map $http_x_amz_target` denies the four `*ClientCredential` targets with 403 — present in the working tree, **not yet live** (feedback F-03) |
| Request limits | nginx `client_max_body_size 1m`; no `limit_req`/`limit_conn` yet (`APP-02`) |

## 4. Artifact mirror

No vendor artifacts are mirrored: there is no proprietary XSD, WSDL, or partner API to cache. `.work/docs/integration/MANIFEST.txt` is therefore absent, and its absence is intentional rather than an oversight.

The one external contract this project **consumes** is AWS Secrets Manager semantics, which is documented by AWS and re-expressed locally in `openapi.yaml` + `API.md`. Those local files are the reviewed source of truth.
